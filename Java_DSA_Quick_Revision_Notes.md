## Java DSA Quick Revision Notes

### Length vs Size

| Data Structure | Syntax         |
| -------------- | -------------- |
| Array          | `arr.length`   |
| String         | `str.length()` |
| ArrayList      | `list.size()`  |
| HashMap        | `map.size()`   |
| HashSet        | `set.size()`   |
| Queue          | `queue.size()` |
| Stack          | `stack.size()` |

### Remember

* Arrays use a **property** → `length`
* Strings use a **method** → `length()`
* Collections use a **method** → `size()`
